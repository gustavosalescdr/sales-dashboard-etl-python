# 📊 Dashboard ETL - Python Automation

Projeto de automação de ETL (Extract, Transform, Load) desenvolvido em Python, com foco em tratamento de dados e preparação para análise em dashboards.

---

## 🚀 Objetivo do Projeto

Este projeto tem como objetivo automatizar o processo de extração, transformação e carregamento de dados de vendas, organizando as informações para análise e visualização em ferramentas como Power BI ou similares.

---

## ⚙️ Tecnologias Utilizadas

- Python 🐍
- Pandas
- Automação de processos (ETL)
- Jupyter Notebook (se aplicável)
- Git & GitHub

---

## 📁 Estrutura do Projeto

├── data/ # Arquivos de entrada e saída
├── notebooks/ # Análises e testes
├── scripts/ # Código principal de ETL
├── README.md


---

## 🔄 Etapas do ETL

### 1. Extract (Extração)
Coleta de dados brutos de arquivos ou fontes externas.

### 2. Transform (Transformação)
Tratamento de dados:
- limpeza de valores nulos
- padronização de colunas
- formatação de datas
- ajustes de tipos de dados

### 3. Load (Carga)
Organização dos dados prontos para análise ou exportação.

---

## 📊 Resultados

Os dados tratados permitem:
- Melhor análise de vendas
- Criação de dashboards mais precisos
- Apoio à tomada de decisão
